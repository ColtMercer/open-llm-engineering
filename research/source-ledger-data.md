# Source ledger: open pretraining data and reproducible model projects

Last reviewed: **2026-07-12**

This ledger is the evidence base for the data chapters. It favors publisher-maintained dataset cards, project repositories, licenses, and original papers. A link in this ledger proves only the adjacent claim; it does not imply that every item inside a corpus is cleared for every use.

## Reading rules

- **Corpus size is not a universal scalar.** Bytes may be compressed or uncompressed; “tokens” depend on a named tokenizer; document counts depend on the unit of extraction.
- **Repository license is not corpus license.** An Apache-2.0 data-processing repository can process a corpus whose documents have many different rights holders.
- **Open access is not the same as open data.** A gated download, a public URL list, a database licensed under ODC-By, and a corpus of individually permissive works are different legal and technical states.
- **Reproducible recipe is not reproduced run.** Exact data order, deleted records, random seeds, software versions, optimizer state, hardware behavior, and compute all matter.

## Claims intentionally not made

- No corpus here is described as “copyright free.”
- No dataset is called “best” or “highest quality” based only on its publisher’s benchmark.
- Token counts from different cards are not compared as if they used the same tokenizer.
- Availability checked today is not promised indefinitely; gated terms, deletion requests, mirrors and Hub implementations can change.
- “Fully open” is used only with an explicit artifact checklist, not as a synonym for downloadable weights.
